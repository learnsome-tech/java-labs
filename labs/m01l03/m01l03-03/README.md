## Goal

You can trace a program from source to class file to loaded class to native code, explain when a class is initialised, and use the single file launcher for a quick script.

In the lesson: In the folder, compile the source. List the class files and there is one, named after the class rather than after the file, which is why the two names have to agree for a public class. Run the class and you get the same two lines the last panel showed. Nothing else was needed: no project file, no dependency, no build tool. Hold on to that, because in two lessons a build tool arrives and it is easy to believe it is doing something magical. It is doing this, with the file lists worked out for you.
