## Goal

You can choose suitable primitive and reference types, explain boxing, and avoid accidental null values at an API boundary.

In the lesson: This small class shows the primitive choices you will meet most often. An int covers ordinary whole numbers. A long is for values that can exceed that range, and the suffix on the literal tells the compiler to treat it as a long. A double stores a fractional value, though money usually deserves a decimal type from a library. A boolean stores true or false. A char stores one UTF sixteen code unit, which is useful for a single symbol but is not a complete model for every human character. The names on the left tell the reader what each value means.
