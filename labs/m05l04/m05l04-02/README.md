## Goal

You can use AssertJ assertions that describe values, collections, and exceptions in readable failure messages.

In the lesson: The static import makes assert that available as the beginning of a fluent sentence. The assertion says that the list contains exactly these two values in this order. If one value is missing, extra, or moved, the failure describes the difference. That is more useful than comparing a boolean and writing a custom message. Choose the strongest assertion that matches the contract, because a precise check documents what matters.
